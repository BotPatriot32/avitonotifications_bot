# Уведомления Авито → Telegram

Бот присылает в Telegram уведомления о **новых сообщениях** и **новых заказах** с Авито.
Работает круглосуточно на бесплатном GitHub Actions — твой ПК для этого включать не нужно.

## Как это работает

GitHub каждые ~5 минут сам запускает скрипт. Скрипт получает токен Авито по твоему
персональному приложению, смотрит новые входящие сообщения и заказы и присылает в Telegram
только то, что появилось с прошлой проверки. Что уже отправлено — помнит в `state.json`.

## Установка (один раз, ~10 минут)

### 1. Создай репозиторий на GitHub
1. Зайди на https://github.com/new
2. Имя любое (например `avito-notify`), сделай репозиторий **Private** (приватным).
3. Создай его.

### 2. Залей сюда эти файлы
Самый простой путь — кнопка **"uploading an existing file"** на странице нового репозитория,
и перетащи туда все файлы из этой папки (включая папку `.github`).

Либо через консоль:
```bash
git init
git add .
git commit -m "Avito notifier"
git branch -M main
git remote add origin https://github.com/ТВОЙ_ЛОГИН/avito-notify.git
git push -u origin main
```

### 3. Добавь секреты
В репозитории: **Settings → Secrets and variables → Actions → New repository secret**.
Добавь 4 секрета (имя → значение):

| Имя секрета            | Значение                                              |
|------------------------|-------------------------------------------------------|
| `AVITO_CLIENT_ID`      | твой client_id приложения Авито                       |
| `AVITO_CLIENT_SECRET`  | твой client_secret приложения Авито                   |
| `TELEGRAM_BOT_TOKEN`   | токен бота от @BotFather                               |
| `TELEGRAM_CHAT_ID`     | твой chat_id (см. ниже, как узнать)                    |

> Как узнать `chat_id`: напиши что-нибудь своему боту в Telegram, затем открой в браузере
> `https://api.telegram.org/bot<ТОКЕН>/getUpdates` — в ответе найди `"chat":{"id": ... }`.

### 4. Включи и проверь
1. Вкладка **Actions** → если просит подтвердить запуск воркфлоу, нажми **"I understand… enable"**.
2. Слева выбери **"Avito → Telegram notifier"** → справа **"Run workflow"** → запусти вручную.
3. Первый запуск пришлёт «✅ Бот уведомлений Авито запущен» и запомнит текущие чаты/заказы
   как уже виденные (чтобы не спамить историей). Все **новые** сообщения и заказы после этого
   будут приходить автоматически.

Дальше ничего делать не нужно — GitHub будет запускать бота каждые ~5 минут сам.

## Локальный запуск (для проверки)

```bash
pip install -r requirements.txt
# заполни .env по образцу .env.example, затем:
python avito_notifier.py
```
(для подхвата `.env` локально можно `pip install python-dotenv` и раскомментировать загрузку,
либо просто выставить переменные окружения вручную.)

## Частые вопросы

**Заказы не приходят.** API заказов (Авито Доставка) доступно не на всех аккаунтах. Если доступа
нет, скрипт это просто пропускает, а сообщения продолжают работать. В логах запуска (вкладка
Actions → конкретный запуск) видно строку `заказы: нет доступа` или `заказы недоступны`.

**Задержка до 5–10 минут.** Это ограничение бесплатного расписания GitHub Actions. Для мгновенных
уведомлений нужен webhook на постоянном сервере — это отдельная история, скажи, если нужно.

**Лимит бесплатных минут.** Запуск занимает ~20–30 секунд. Даже круглосуточно это укладывается
в бесплатные 2000 минут/мес для приватных репозиториев.
